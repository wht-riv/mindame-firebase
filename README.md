# みんだめ v5（デモ版）

## 変更内容
- 利用者向けの「止まった」を「できなかった」へ変更
- 自分の言い訳集は「実際にできなかった理由」の回数順だけを表示
- リアクションを「🌱」1種類へ変更
- 🌱リアクション数を投稿カードに表示
- みんなの欄には、言い訳だけでなく「最初の一歩」も表示
- 表示形式は「『眠い』→ パソコンを開く」
- 全ジャンルの共有記録を一覧表示
- 作戦保存後に、今日の予測と最初の一歩をそのまま匿名共有するか選択
- 初回の言い訳3つ、過去の最初の一歩、実際にできなかった理由の集計を維持
- デモモードは有効

## 本番利用に戻す
`src/App.jsx` の `const DEMO_MODE=true;` を `false` に変更します。
