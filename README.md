# みんだめ v4.2（デモ版）

## 反映した修正
- 初回登録の言い訳を合計ちょうど3つに変更
- 候補と自由記述を組み合わせて3つ登録可能
- 自由入力した「最初の一歩」を次回候補へ保存
- 最初の一歩を「最近使った／よく使う／おすすめ」に分けて表示
- 言い訳集の初期並びを「実際に止まった回数順」に変更
- 予測と違う理由で止まった場合、実際の理由側へカウント
- 別理由を言い訳集へ追加するか選択可能
- 言い訳ごとに「実際に止まった／予測に使った／それでも動けた／後から見つかった」を表示
- 公開画面から「ネタ」という表現を削除
- 公開する文章を自由に編集し、そのまま公開または公開しない方式へ変更
- 研究用の言い訳と公開文章は別フィールドで保存
- デモモードは有効のまま

## 本番利用へ戻す
`src/App.jsx` の `const DEMO_MODE=true;` を `false` に変更してください。
