# みんだめ v5.4

言い訳を事前に予測し、その状態でもできそうな最初の一歩を決め、翌日に予測と実際を振り返るWebアプリです。

## v5.4の改善

- 毎日の言い訳候補は、本人が登録したカードだけを表示
- 「言い訳 → 一歩」を「〇〇な日でも、△△ならできるかも」という文章で表示
- 小さく具体的な一歩を入力する案内を追加
- 踏み出せた一歩に、実行できた日の言い訳内訳を表示
- みんなの記録にも、言い訳と最初の一歩を一文で表示
- リアクション表示を「👣 踏み出せそう」に変更
- 既存のFirebaseコレクション participantsV4 / publicPostsV4 を継続利用

## デモモード

`src/App.jsx` の `const DEMO_MODE=true;` を `false` にすると、本番用の1日1回制限になります。
